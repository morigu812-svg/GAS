01 / 接続設定

まずGoogle CloudでApps Script APIを有効化し、OAuthクライアントIDを設定してください。
この画面はGitHub Pages上の静的ページです。OAuthクライアントIDは入力欄に入力するだけで、リポジトリには保存しません。アクセストークンはこのページのメモリ内だけに保持し、localStorageには保存しません。

03 / 安全確認

• このサイトはGoogleのOAuthアクセストークンをサーバーに送信しません。
• GitHub Pagesは公開サイトです。秘密鍵・パスワード・OAuthクライアントシークレットをコードに追加しないでください。
• APIへのアクセスは、Google認証したアカウントの権限に従います。
• GASのソース更新はプロジェクト内の全ファイルを置き換えるため、別のタブで同じプロジェクトを編集しないでください。
